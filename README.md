# 🛒 BlinkIT Grocery Sales Analysis

## 📌 Project Overview

This project focuses on analyzing BlinkIT grocery sales data using Microsoft Power BI. The objective is to transform raw sales data into meaningful insights through interactive dashboards and visualizations.

The dashboard helps understand sales performance, product distribution and outlet-related trends to support better business decisions.

## 🎯 Project Objectives

- Analyze overall grocery sales performance.
- Understand sales distribution across different product categories.
- Evaluate outlet performance and characteristics.
- Identify patterns and trends in grocery sales.
- Present business insights through interactive visualizations.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization.
- **Microsoft Excel** – Dataset inspection and data handling.
- **Power Query** – Data cleaning and transformation.

## 📊 Dashboard Features

- Overall sales performance analysis.
- Item category-wise sales analysis.
- Outlet-wise sales comparison.
- Interactive slicers and filters.
- KPI cards for important business metrics.
- Visual representation of sales trends and distributions.

## 💡 Business Value

This analysis helps understand sales patterns, compare outlet performance and identify product categories contributing to overall sales.

It demonstrates how data visualization can convert raw business data into useful information for decision-making.
